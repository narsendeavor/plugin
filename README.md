# NARS'S ENDEAVOR

An all-in-one Roblox Studio plugin and utility suite engineered to streamline development workflows, empower builders, and enhance productivity.

**Nars's Endeavor** is an all-in-one Roblox Studio Lite utility suite designed to bring essential development tools together in one convenient interface.

The suite combines building tools, scripting utilities, asset management, camera controls, icons, and other development features into a streamlined workspace.

---

## Features

| # | Feature | Description |
|:---:|:---|:---|
| 01 | **Toolbox Store** | Search and use Roblox assets directly from the studio environment. |
| 02 | **Archimedes Tools** | Precision geometry utilities for transformations, rotations, angles, and curve-based building. |
| 03 | **Audio Player** | Built-in audio utility for quickly testing and controlling audio assets. |
| 04 | **Utility Suite** | Additional development utilities including Terrain tools, Asset Importer, and other productivity tools. |
| 05 | **Lucide Icons** | Integrated Lucide icon resources for creating clean and consistent interfaces. |
| 06 | **Fly Camera Fokus Speed** | Free camera movement with adjustable focus and movement speed for easier scene navigation. |
| 07 | **Ecode** | Integrated Lua code editor and development environment for writing, managing, and executing scripts. |
| 08 | **Gizmo Axis** | Interactive axis gizmos for manipulating and working with objects along the X, Y, and Z axes. |

---

## Ecode

**Ecode** is a lightweight code development environment integrated into Nars's Endeavor, providing a dedicated workspace for scripting, file management, script execution, and console output.
