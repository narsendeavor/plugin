NARAKU • TOOLBOX is an all-in-one suite designed to accelerate development workflows inside Roblox. It combines high-utility building utilities, asset management tools, and developer shortcuts into a single, unified interface.

---

## Overview

NARAKU • TOOLBOX reduces repetitive tasks by providing seamless in-studio search capabilities, geometric placement tools, and quick-launch execution scripts. Built for developers and creators, it provides direct access to vital assets, audio testing, and advanced geometry tools right from your canvas.

## Core Features

### <img src="https://api.iconify.design/lucide:shopping-bag.svg?color=%23ffffff" width="16" height="16"/> Toolbox Store & Search
* Direct asset injection for Models, Decals, and Audio.
* Search and copy Asset IDs instantly without navigating through external browsers.

### <img src="https://api.iconify.design/lucide:compass.svg?color=%23ffffff" width="16" height="16"/> Archimedes Tools
* Precision arc and circular structure rendering.
* Configurable axis transformation, custom angles, and continuous rendering logic.

### <img src="https://api.iconify.design/lucide:music.svg?color=%23ffffff" width="16" height="16"/> Audio Player
* Integrated audio player with playback bar, time tracking, and instant ID addition for quick audio testing.

### <img src="https://api.iconify.design/lucide:wrench.svg?color=%23ffffff" width="16" height="16"/> Utility Suite
* **Terrain Tools**: Streamlined environment manipulation controls.
* **Asset Manager**: Fast importing options for external files and decals.
* **Fly GUI**: Free-cam and spatial movement navigation during studio testing.
* **Developer Utilities**: One-click launch access for Dex Plus Plus and Infinity Yield.
